# Seq-rHpy-calculation

This repository contains the code and analysis for the Seq-rHpy calculation project.

## Contents

- `*.ipynb` — Google Colab/Jupyter notebook containing the complete analysis, including code and saved outputs.

## Usage

The notebook can be opened directly in Google Colab or Jupyter Notebook.

Open in Colab:
1. Download or clone the repository.
2. Open the `.ipynb` notebook in Google Colab.
3. Run the cells as required.

## Project

The notebook contains the computational workflow, data processing, model calculations, and results associated with the Seq-rHpy analysis.
